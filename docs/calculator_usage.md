# Документация: Калькулятор

## Описание
Простой консольный калькулятор, реализующий базовые арифметические операции: сложение, вычитание, умножение и деление.

## Установка
Программа не требует установки. Достаточно иметь интерпретатор Python версии 3.6 или выше.

## Запуск
```bash
python calculator.py
```

## Использование
1. Запустите программу
2. Введите первое число
3. Выберите операцию (+, -, *, /)
4. Введите второе число
5. Получите результат

## Поддерживаемые операции
- `+` - сложение
- `-` - вычитание
- `*` - умножение
- `/` - деление (с проверкой деления на ноль)

## Примеры
```
Введите первое число: 10
Введите операцию (+, -, *, /): *
Введите второе число: 5
Результат: 50.0
```

```
Введите первое число: 15
Введите операцию (+, -, *, /): /
Введите второе число: 3
Результат: 5.0
```

## Обработка ошибок
- При попытке деления на ноль будет выведено сообщение: "Ошибка: Деление на ноль невозможно"
- При вводе нечисловых значений будет выведено сообщение об ошибке
- При выборе недопустимой операции программа завершится с сообщением "Неверная операция"
